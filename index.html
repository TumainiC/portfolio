/02

TrOCR fine-tuning pipeline

A modular 3-stage document intelligence pipeline: layout detection (CRAFT/DBNet) to find text regions, fine-tuned TrOCR (LoRA, r=16) to transcribe them, and an LLM post-processing layer for structured JSON extraction. Trained on 20K+ historical documents on GCP. The key architectural decision was keeping each stage scoped to one problem — no single model doing everything.
